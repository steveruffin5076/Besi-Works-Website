About Besi Works

Besi Works is an independent app and game studio focused on turning everyday habits — like budgeting — into something genuinely motivating. We believe the best tools aren't the ones that demand discipline, they're the ones that reward you for showing up.

Every app we build starts with the same question: how do we make this a habit you actually want to keep?
